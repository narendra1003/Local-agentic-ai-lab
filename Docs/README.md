# Documentation

This directory contains detailed documentation for the **Local Agentic AI Lab** project.

The project documents experiments with locally hosted language models, OpenCode, and Ollama to explore practical AI-assisted coding and agentic workflows on consumer-grade hardware.

## Documentation Structure

### Setup

**[setup.md](setup.md)**

Documents the local environment setup, including:

* OpenCode configuration
* Ollama setup
* Local model integration
* General workflow configuration

### Hardware Environment

**[hardware.md](hardware.md)**

Documents the hardware used for the experiments and the resource constraints that influence model selection and workflow design.

### Experiments

**[experiments.md](experiments.md)**

Contains a chronological record of experiments, including:

* Objectives
* Models tested
* Tasks performed
* Results
* Observations
* Conclusions

### Model Evaluation

**[model-evaluation.md](model-evaluation.md)**

Documents the methodology used to evaluate models for different tasks, including:

* Instruction following
* Tool calling
* Code understanding
* Code generation
* Repository analysis
* Speed and resource usage

### Findings

**[findings.md](findings.md)**

Contains the key learnings and conclusions derived from the experiments.

## Documentation Principles

The documentation focuses on recording actual experiments and observations.

Results are documented based on practical testing rather than assumptions or benchmark scores alone.

This project is actively evolving, and the documentation will be updated as new experiments, models, configurations, and workflows are explored.
